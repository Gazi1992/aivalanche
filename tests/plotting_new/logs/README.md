# Logs Directory

This directory contains all debugging and monitoring logs for the Data Visualization Studio application.

## Log Files

### 1. **backend_debug.log**
- General backend server logs
- API request/response logging
- Data processing operations
- Error messages and stack traces
- Dashboard building activities

### 2. **frontend_payload.json**
- The latest JSON payload sent to the frontend
- Contains the complete dashboard configuration
- Includes all plot data and layout settings
- Useful for debugging visualization issues

### 3. **llm_conversations.log**
- Complete history of LLM (Gemini) interactions
- User messages and AI responses
- Request type detection (data, visualization, transformation, etc.)
- Generated configurations and transformations
- API calls to Gemini with prompts and responses
- Timestamp for each interaction

### 4. **generated_config_*.json**
- Timestamped copies of all configurations generated by the LLM
- Each file represents a visualization configuration created from chat
- Filename format: `generated_config_YYYYMMDD_HHMMSS.json`
- Contains the complete configuration structure used to build dashboards

## Usage

These logs are essential for:
- Debugging issues with plot generation
- Understanding LLM decision-making process
- Tracking user interactions and system responses
- Analyzing configuration generation patterns
- Troubleshooting data processing errors

## Note

- Logs are appended continuously (except backend_debug.log which overwrites on restart)
- LLM conversation log grows over time and may need periodic cleanup
- Generated config files accumulate and can be deleted after review
